# Preferências do projeto

- Em interfaces novas, prefira botões de ação com cantos suavemente arredondados, em torno de 12 px. Respeite a identidade existente e pedidos específicos.
- Ao concluir alterações do Café com Letras, execute as verificações do projeto, crie o commit e publique pelo fluxo GitHub → Cloudflare Pages da branch `main`. Confirme a publicação no domínio oficial. Se a solicitação atual pedir para não publicar, mantenha as mudanças fora de produção.
